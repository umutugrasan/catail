For Windows, free and open source

Queue up your screenshots, paste them with one Ctrl+V.

Sending ten images to ChatGPT, WhatsApp or a document? Stop flipping between windows. Catail keeps your screenshots, copied text and files in a queue, then drops them all in the same order.

Pick your cat

The app's colors, its paw cursors and the cat waiting in the box all follow the one you pick. The black cat is the dark theme. Rather have no cat? There's a plain theme too. This page follows your cat as well, try it.

Picking a cat comes with the next release. For now the app has the orange cat.

Done in three steps

  1. 1

    Collect

    Press PrtSc, pick an area, add it to the queue. In text mode every Ctrl+C joins the queue too.

  2. 2

    Arrange

    Click the badge to open the queue. Drag the cards to reorder them, delete the ones you don't want.

  3. 3

    Drop

    While the queue has items, Ctrl+V pastes them all in the order you took them. Whatever was on your clipboard comes back afterwards.

Open source, code in the open

All of Catail's code is on GitHub. Read what it does, build it yourself, report a bug or suggest an idea. It's made with Tauri 2: a Rust core, with a React and TypeScript interface.

Windows may warn you; here's why

The installer isn't code-signed yet, as we don't have a signing certificate. So Windows SmartScreen may call it an "unknown publisher". If you'd like to go ahead:

Windows protected your PC More info Run anyway
  1. In the window that pops up, click More info.
  2. Press Run anyway, which appears below.

Not comfortable with that? Read the code and build it yourself.

Questions

PrintScreen opens the Windows Snipping Tool

Windows 11 gives this key to the Snipping Tool by default. In Settings → Accessibility → Keyboard, turn off "Use the Print screen key to open screen capture", then restart Catail. If another tool that uses the key, like Lightshot, is running, the shortcuts clash. You can also change the shortcut in Catail's settings.

Does it break normal Ctrl+V?

No. Catail only takes over Ctrl+V while there's something in the queue. Once it's empty, Ctrl+C and Ctrl+V work as they always did.

Where do my screenshots go?

Nowhere. Images in the queue sit in your computer's temp folder and are deleted when the app closes. If you use translation, text is sent to Google Translate only when you press Translate.

Does it cost anything?

No. It's free to download and use, with no account. The code is open under the MIT license.

Does it run on macOS or Linux?

Windows only for now. macOS is planned for later; Linux isn't planned.

I used Stack Screen

Catail is its new name, but it installs as a separate program. Your settings move over the first time it opens. Then uninstall Stack Screen from Settings → Apps, or the shortcuts will clash.
